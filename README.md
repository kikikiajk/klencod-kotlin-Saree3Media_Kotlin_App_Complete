# تطبيق سريع ميديا (Saree3 Media) - Kotlin

تطبيق أندرويد مصمم بواجهة ملونة حديثة وأيقونة احترافية (`512x512`) لتنزيل الفيديوهات والصوتيات من **تيك توك** و **يوتيوب**.

## المميزات المنفذة:
1. **نافذة منبثقة فوق تيك توك ويوتيوب (`ShareReceiverActivity`):** عند الضغط على مشاركة في تيك توك أو يوتيوب واختيار **«تنزيل عبر سريع ميديا»**، تظهر نافذة عائمة شفافة فوق التطبيق بدون الانتقال لشاشة كاملة، تتيح تسمية الملف واختيار فيديو أو صوت وبدء التنزيل فوراً.
2. **واجهة رئيسية ملونة ومنظمة (`MainActivity`):** اختيار المنصة (تيك توك / يوتيوب)، لصق الرابط، كتابة اسم مخصص للملف، واختيار الصيغة والجودة.
3. **حفظ الفيديوهات في الاستوديو مباشرة (`MediaStore`):** أي فيديو يتم تنزيله يظهر فوراً في معرض/استوديو الصور والفيديو (`Movies/Saree3Media`).
4. **اختيار مجلد مخصص للصوتيات في أول تنزيل (`Storage Access Framework`):** عند تنزيل أول ملف صوتي `MP3`، يطلب التطبيق تحديد المجلد الذي ترغب بحفظ الصوتيات فيه ويحفظ الصلاحية تلقائياً للتنزيلات القادمة.
